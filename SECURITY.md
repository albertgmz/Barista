# Security Policy

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/albertgmz/Barista/security/advisories/new). Do not
include sensitive details in a public issue.

Include the affected version, impact, reproduction steps, and any suggested mitigation. The project
will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is
available. See [`docs/SECURITY.md`](docs/SECURITY.md) for the current security design review.
